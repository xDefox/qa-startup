# Persona и пилот — webscope

Основа: economic-audit.md + PLAN.md §1, 3, 11.

## Persona покупателя
- **Кто:** владелец небольшого сайта (кафе, салон, магазин, агентство с 1–5 сайтами).
- **Боль:** не понимает технические отчёты (Lighthouse); нужен человеко-читаемый текст + готовое ТЗ для разработчика.
- **Бюджет:** $12–18/мес на сайт; готов платить, если видит исправленные находки через неделю.
- **Канал:** SEO по запросу «проверить сайт на ошибки» + партнёрки CMS.

## Критерии пилота (10 платящих)
- Пилот успешен, если:
  1. Пользователь получил отчёт.
  2. Через 7 дней повторный скан показывает <50% тех же serious.
  3. Пользователь подтвердил «да, исправил» в интерфейсе или по email.
- Без метрики действия пилот — не доказательство ценности подписки.

## Биллинг (структура)
- Модели: site-plan ($12/мес), agency-plan ($149/мес до 40 сайтов).
- Платежи через Stripe (не реализовано — Milestone 4 ⏳).
- До реализации: ручной учёт пилотов с email-подтверждением.
