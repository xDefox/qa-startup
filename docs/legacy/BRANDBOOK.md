# webscope — брендбук

Единый источник правды по визуальному стилю. Всё здесь взято из
`src/webscope/webapp/templates/base.html` — если правило меняется, правится
и этот файл. Других дизайн-систем в проекте нет.

Принцип: **интерфейс — это инструмент, а не витрина**. Скромная светлая база,
один синий акцент и строгая шкала серьёзности. Цвет несёт смысл: красный —
блокирует клик, оранжевый — мешает клиенту, серый — мелочь.

## Палитра

Все цвета — CSS-переменные в `:root`. Клиентский код берёт только
переменные, не хардкод.

### Светлая тема (по умолчанию)

| Переменная | HEX | Где |
|---|---|---|
| `--bg` | `#f6f7f9` | фон страницы, вложенные блоки (`.step`, `.pill`) |
| `--card` | `#ffffff` | фон карточек, шапки, полей ввода |
| `--ink` | `#1c2333` | основной текст, заголовки |
| `--muted` | `#5b6474` | подписи, вторичный текст, `meta` |
| `--line` | `#e4e7ec` | границы карточек, таблиц, полей |
| `--accent` | `#2563eb` | ссылки, кнопки, фокус, бегущая полоска |
| `--accent-hover` | `#1d4ed8` | наведение на акцент |
| `--ok` | `#087443` | оценка «отлично», бейдж успеха |

### Тёмная тема

| Переменная | HEX | Примечание |
|---|---|---|
| `--bg` | `#0b1026` | тёмно-синий, не чистый чёрный |
| `--card` | `#101625` | фон карточек |
| `--ink` | `#e6e8ee` | основной текст |
| `--muted` | `#9aa2b4` | вторичный текст |
| `--line` | `#232a3d` | границы |
| `--accent` | `#4f9bff` | светлее светлой темы — контраст на тёмном фоне |
| `--accent-hover` | `#6aa8ff` | наведение |
| `--ok` | `#22c55e` | успех |

Тёмная тема подключается тремя способами: явный `data-theme="dark"`,
`data-theme="light"`, либо системная настройка через
`@media (prefers-color-scheme: dark)`. Выбор пользователя хранится в
`localStorage` под ключом `webscope-theme`.

### Шкала серьёзности

Одна и та же семантика в обоих темах. В бейджах фон фиксированный, текст —
тёмный (чтобы контраст не падал в тёмной теме на светлой «табличке»).

| Уровень | Переменная | Светлый HEX | Тёмный HEX | Бейдж фон / текст |
|---|---|---|---|---|
| Критично | `--critical` | `#b42318` | `#f87171` | `#fee4e2` / `#b42318` |
| Серьёзно | `--serious` | `#d97706` | `#f59e0b` | `#fef0c7` / `#92400e` |
| Умеренно | `--moderate` | `#b54708` | `#f59e0b` | `#fdf1e3` / `#9a3412` |
| Мелочь | `--minor` | `#667085` | `#9aa2b4` | `#f2f4f7` / `#475467` |
| Успех | `--ok` | `#087443` | `#22c55e` | `#dcfae6` / `#087443` |

`--serious-ink` (`#92400e`) — дублирует цвет текста бейджа «серьёзно», используется
для жёлтой плашки примечаний (`.note-context`).

## Шрифты

Системный стек — без веб-шрифтов, чтобы не было запроса к стороннему CDN и
CLS от подгрузки:

```
-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
"Helvetica Neue", Arial, sans-serif
```

Моноширинный — системный `monospace` (для `code`, селекторов, сниппетов).

| Элемент | Размер | Начертание |
|---|---|---|
| Оценка (`.score`) | 46px | 700, `-0.03em` |
| Заголовок страницы (`h1`) | 30px | 700, `-0.02em`, `line-height: 1.25` |
| Заголовок карточки (`h2`) | 21px | 700, `-0.01em` |
| Логотип (`.top .logo`) | 19px | 700, `-0.02em` |
| Балл в списке (`.site-row-score`) | 20px | 700 |
| Заголовок блока (`h3`) | 16px | 700 |
| Текст, кнопки, поля | 16px | 400 / кнопки 700 |
| Мелкий текст (`.small`) | 14px | 400 |
| Подписи полей, `.fix` | 14px | 400, цвет `--muted` |

(`-0.03em` у оценки → `-0.01em` у `h2`). Это уплотняет крупный текст.

## Формы и скругления

Радиусы кодируют иерархию: крупные контейнеры — сильнее скруглены.

| Элемент | Радиус |
|---|---|
| Карточка (`.card`) | 14px |
| Вложенный блок (`.step`) | 12px |
| Кнопки, поля ввода, `.error`, `.flash` | 10px |
| Сниппет кода, `.pill`, `.note-context` | 8px |
| `code` внутри находки | 5px |
| Бейджи, переключатель темы | 999px (полная капсула) |
| Полоска «заклеенного» балла | 2px |

Единица отступа — 4px. Типовые значения: 8 / 12 / 14 / 16 / 18 / 22 / 24 / 28.

## Тени

У карточки двойная тень — тонкая контурная плюс глубокая размытая:

```css
box-shadow:
  0 1px 1px rgba(15, 23, 42, 0.01),
  0 10px 30px -20px rgba(15, 23, 42, 0.8);
```

Больше нигде теней нет — карточка единственный «поднятый» элемент.

## Движение

Всё уважает `prefers-reduced-motion`. Длительности подобраны по ощущению
отклика, а не декорации.

| Эффект | Длительность | Тайминг |
|---|---|---|
| Фон кнопки при наведении | 120ms | `ease-in-out` |
| Цвет/фон/граница | 160ms | `ease` |
| Смена темы (глобальная) | 240ms | `ease` |
| Иконка темы (поворот) | 320ms | `ease` |
| Спиннер (вращение) | 800ms | `linear`, бесконечно |
| Бегущая полоска | 1400ms | `ease-in-out`, бесконечно |

Иконка переключателя темы при смене доворачивается на `20deg` и возвращается
при следующем переключении.

## Спиннер проверки

Блок `.scan-progress`: вращающийся кружок (`.scan-spinner`, 18px, граница
`--accent` на 25%-ном кольце) плюс бегущая полоска внизу через `::after`.
`role="status"` + `aria-live="polite"` — скринридер объявит начало проверки.
При `prefers-reduced-motion: reduce` анимации замедляются вдвое, а не отключаются.

## Сетка и раскладка

- Контейнер `main`: `max-width: 940px`, отступы `28px 20px 60px`, по центру.
- Шапка `.top`: `padding: 14px 24px`, логотип слева, переключатель темы справа (`margin-left: auto`).
- Ряды `.row`: `flex`, `gap: 12px`, `flex-wrap`, элементы `flex: 1 1 180px`.
- Список сайтов `.site-row`: колонки URL / мета слева, балл и стрелка справа.

## Доступность (не обсуждается)

- Контраст текста — минимум **5.2:1** (WCAG AA требует 4.5:1 для обычного текста).
- Видимый фокус: `outline: 2px solid var(--accent)` с `outline-offset: 2px`.
- Фокус кликом мыши (`:focus:not(:focus-visible)`) убирается, фокус с клавиатуры — остаётся.
- `theme-color` в `<head>` подстраивает цвет адресной строки под светлую тему.
- Бейджи серьёзности — светлый фон + тёмный текст в обеих темах, чтобы контраст не падал.
