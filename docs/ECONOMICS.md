| Тар | Цена/мес | Цена/год | ЦА | Лимиты | EAA-протокол |
|---|---|---|---|---|---|

## 3. Обоснование цен (почему $12, $59, $149)

### $12 (SOLO) — «цена кофе»
- **Психологический порог:** < $10 = «подозрительно дешево/низкое качество», > $15 = требует согласования в бюджете ИП.
- **Покрывает инфраструктуру:** сервер Playwright + SQLite + email/Telegram ≈ $1–2/мес на сайт. Остаток $10 — поддержка, маркетинг, R&D.
- **Benchmarks:** Ahrefs Lite $99/мес (1 сайт), SE Ranking $39/мес, UptimeRobot $8/мес (просто мониторинг). $12 — дешевле любого специализированного инструмента, но даёт непрерывный контроль.

### $59 (STUDIO) — агентство 1–5 сайтов
- **3–5× SOLO:** агентство с 3–5 сайтами платит как за 3–5 Solo, но получает daily-сканы, flow-runs (20/нед), EAA-протокол.
- **Benchmarks:** Semrush Agency $449/мес (5 проектов), AgencyAnalytics $49/мес (неограниченно). $59 — в корзине «достаточно дешево, чтобы не считать».

### $149 (AGENCY) — агентство 10+ сайтов
- **~2.5× STUDIO:** разница в white-label, API, SLA, unlimited sites, приоритетная поддержка.
- **Benchmarks:** Semrush Business $449, Ahrefs Advanced $399. $149 — существенно ниже, давая же пер-сайт модель.

## 4. Unit Economics (целевые метрики)

| Метрика | Цель | Обоснование |
|---|---|---|
| **ARPU** | ~$18/мес | смесь: 60% SOLO ($12), 30% STUDIO ($59), 10% AGENCY ($149) → $0.6×12 + $0.3×59 + $0.1×149 ≈ $18 |
| **CAC** | ~$30 | SEO-контент + Telegram-бот + партнёрки CMS. Тестовый трафик $250 (SEO) + $600–800 (paid) → 10–15 leads → ~1 платящий → $30–80. Целевой $30 при оптимизации. |
| **Churn (мес)** | ≤ 12% | Сайт починили → отписались. Лечится: портфель агентств (churn < 5%), EAA-обязательность (регулярные перепроверки). |
| **LTV** | ~$150 | $18 / 12% = $150. При churn 12% средний клиент живёт 8.3 мес. |
| **LTV/CAC** | ~5× | $150 / $30 = 5. Целевой порог SaaS > 3×. |
| **FP-rate** | < 10% | Доля находок, отклонённых как ложные. Критично для доверия. |
| **Pilot success** | ≥ 60% пилотов с `fixed_findings > 0` за 14 дней | Метрика действия из PLAN.md §9. 10 пилотов, 7 дней до повторного скана. |

> См. `ECONOMIC_JUSTIFICATION_RU.md` §§1–3, `economic-audit.md` §3.

## 5. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| **FP-rate > 10%** | Средняя | Высокое (утрата доверия) | evidence-first: браузер + скриншот + сниппет; FP-кнопка в UI; дедуп axe |
| **Churn после фикса** | Высокая | Высокое | Портфель агентств (sticky), EAA-регулярность, weekly-алерты как привычка |
| **Конкуренты (Lighthouse/SignalCrawler)** | Низкая | Среднее | Дифференциация: детерминизм + AI + archetype + FP-метрика; continuous-сервис vs разовый скан |
| **CAC > $80** | Средняя | Среднее | SEO-first (органический), партнёрки CMS (Tilda/Shopify referral), контент-маркетинг |
| **Хостинг Playwright** | Низкая | Среднее | 1 браузер/прогон, кэш контекста, лимит страниц/времени, `WEBSCOPE_SCAN_TIMEOUT` |

## 6. План проверки спроса (Milestone 5, PLAN.md §9)

1. **Лендинг:** «Проверьте сайт бесплатно» → веб-интерфейс уже работает как лендинг (вставил URL → отчёт).
2. **10–15 разговоров** с владельцами сайтов/агентствами: как проверяете, сколько платите за аудит, что «достаточно хорошо».
3. **10 платящих пилотов** (Solo $12 или Studio $59), ≥ 14 дней, метрика = `fixed_findings > 0` во 2-м прогоне (через 7 дней).
4. **Критерий успеха:** ≥ 60% пилотов исправили ≥ 1 находку; FP-rate < 10%.
5. **Телеметрия:** FP-rate, retention, time-to-first-fix.
