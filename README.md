# WebScope — честные аудиты сайтов для малого бизнеса и ИП

**Одна фраза:** открываем сайт как клиент — WebScope находит проблемы, которые
мешают оставить заявку. Честно: никаких «всё работает» по словам, только подтверждённые
дефекты в реальном браузере.

---

## Что это сейчас

- **Продукт** с веб-интерфейсом и CLI: продакшн-стенд — https://webscope.duckdns.org/
  (Fly.io; см. `docs/DEPLOY.md`).
- **Экономика — рабочая гипотеза, проверяется пилотом** (не прогноз). Тарифы и пакеты
  описаны в `docs/ECONOMICS.md` (Free — 5 находок, Starter $19, Pro $59, Business $199);
  оплата на сайте пока не подключена, тарифные лимиты — ещё не действуют.

---

## Что даёт сканер

По умолчанию (`webscope scan URL`) проверяет реальные вещи, которые мешают заявкам:

- **Интеракция** — перекрытые кнопки/ссылки: если по ним нельзя кликнуть.
- **Формы** — «мёртвые» формы (заявка не уходит), поля без `name`/`label`,
  placeholder вместо подписи, email/телефон без `autocomplete`/`inputmode`,
  `novalidate` без своей валидации.
- **Ссылки** — битые ссылки (HTTP ≥ 400), таймауты, небезопасные схемы.
- **Консоль** — JS-ошибки, предупреждения, упавшие запросы.
- **Мобильная вёрстка и viewport** — горизонтальный скролл при 320px и переполнение
  элементов; цели касания меньше 24×24 px; meta viewport.

Полный аудит (`webscope scan URL --checks all`) добавляет:

- **Доступность** — axe-core по WCAG 2.2 AA (контраст, alt, заголовки, ARIA...).
- **Контент** — lang, title, meta description, viewport, charset, структура
  заголовков, alt у картинок, Open Graph/Twitter-теги, дубли `id`.

**Честно:** performance пока не проверяется, SEO в смысле «ранжирование/скорость»
не проверяется.

## Отчёт: что считается плохим результатом

- Балл 0–100 (`scoring.py`): ≥90 отлично, 75 хорошо, 55 нормально
  (есть над чем работать), 30 плохо, <30 — критично плохо.
- Главные блокеры: `interaction/button-blocked`, `forms/dead-submit`,
  `links/broken`, `console/error` — выше по весу в оценке скора.
- Находки на чужих доменах (счётчики, карты, реклама) — не дефект сайта:
  выводятся отдельным блоком, на балл не влияют.

## Quick start

```bash
cd /home/kuga/Work/qa-startup

# Веб-интерфейс локально:
.venv/bin/python -m uvicorn webscope.webapp.app:create_app --factory --host 127.0.0.1 --port 8000

# CLI — один скан страницы:
.venv/bin/webscope scan https://ваш-сайт.рф

# Полный аудит + machine-readable форматы:
.venv/bin/webscope scan https://ваш-сайт.рф --checks all --format json
```

- Форматы вывода: text, plain, json, html, sarif, junit.
- Тесты: `pytest -m "not e2e"`.

## Честная сводка

- **Как запустить:** uvicorn (выше) или CLI-скан. CLI-скан не требует регистрации;
  веб-интерфейс закрыт аутентификацией (registration → аккаунт).
- **Проект для массового релиза сейчас — одиночный:** разработчик-основатель
  (Python/FastAPI, Playwright/axe-core), тесты, CI, интеграции (API, MCP,
  SARIF/JUnit) готовы к командной интеграции. Целевая аудитория —
  ИП/малый бизнес; для корпоративных сегментов пока рано.
