## 1. Почему 5 находок, а не 1 сайт или безлимит?

**5 находок — это 30–40% отчёта.**
- 12–18 находок даёт средний сайт за полный скан
- 5 ≈ 30–40% отчёта: видно ценность, не видно всего
- 6-я находка — естественный момент апсейла
- Абьюз: привязка к email, device fingerprint, Stripe customer. A/B: 5 vs 10.

## 2. Почему гибридная цена (подписка + пакеты + Watchdog)?

**Подписка — для постоянных. Пакеты — для разовых. Watchdog — для частых деплоев.**

| Модель | Цена | Для кого | Почему работает |
|--------|------|----------|-----------------|
| **Free** | 5 находок | Все новые | Воронка, показывает ценность |
| **Starter** | $19/мес | Малый бизнес, SEO, фрилансеры | Постоянные сайты, нужна стабильность |
| **Starter + Watchdog** | $29/мес | Продуктовые команды, частые деплои | Апсейл +$10 = +53% ARPU, удерживает |
| **Pro** | $59/мес | Агентства, команды | API, SARIF, белый ярлык |
| **Пакеты** | $29/10 · $99/50 · $179/100 | Лендинги, визитки, сезонные | Не сгорают, списание за факт скана |

**Каннибализации нет** — сегменты не пересекаются по потребностям и паттернам использования.
- Агентство не купит пакет (им нужен API, SARIF, 25 сайтов)
- Фрилансер не купит подписку (им не нужны 5 сайтов ежемесячно)
- Лендинг не купит подписку (проект живёт 2 недели)

> **Скрытый слайд** — открывать по вопросу о цене.

## 3. Откуда $150/мес и 6 клиентов до безубыточности?

**Фиксированные расходы в месяц:**
- VPS $90
- LLM API $30
- Почта/телеметрия $10
- Бухгалтерия/юридика $20
- **Итого: $150/мес**

**Безубыточность:**
- При Starter $19/мес и марже 85%: $150 / (19 × 0,85) ≈ **9,3 клиента**
- С апсейлами Watchdog (+$10) и Pro ($59): **6 клиентов** покрывают фиксированные расходы

**Бюджет запуска: $800**
- Инфраструктура (VPS, домен, TLS): $120
- LLM API, почта, телеметрия: $60
- Юридика (оферта, платежи): $200
- Тест трафика (Meta, Google): $250
- Резерв: $170

## 4. Откуда CAC $30, LTV $218 и 7×?

| Метрика | Значение | Основание |
|---------|----------|-----------|
| **CAC** | ~$30 | $250 тест трафика / 8 платящих из пилота |
| **LTV** | ~$218 | Взвешенное среднее по 3 моделям (см. ниже) |
| **LTV/CAC** | ~7× | 218 / 30; здоровый SaaS — выше 3× |
| **Payback** | ~1.4 мес | 30 / (27 × 0,85) ≈ 1.3 |

**LTV по моделям (взвешенное):**
- Starter (35%): 8 мес × $19 = $152
- Starter + Watchdog (21%): 10 мес × $29 = $290
- Pro (8%): 14 мес × $59 = $826
- Pay-per-scan (35%): $62.7 (повторка 34% за 6 мес)

**Взвешенный LTV = 0.35×152 + 0.21×290 + 0.08×826 + 0.35×62.7 ≈ $218**

## 5. Чем отличаетесь от Lighthouse, аудита и uptime?

| | Lighthouse | Ручной аудит | Uptime | **webscope** |
|---|---|---|---|---|
| **Что проверяет** | метрики и правила | всё, вручную | сервер отвечает | **клики, формы, заявки** |
| **Когда** | разово | раз в 2–3 недели | 24/7, поверхностно | **еженедельно + дифф** |
| **Язык** | технический | экспертный | технический | **владельца сайта** |
| **Цена** | $0 | $200–3 000 | $6–35/мес | **Starter $19/мес** |
| **Watchdog** | — | — | — | **алерт за 5 мин после деплоя** |

**Границы:** 2FA и капчи — нет; сложный JS — частично; FP — цель <10%.

> **Скрытый слайд** — открывать по вопросу о конкурентах.

## 6. А ложные срабатывания?

- **FP цель: <10%** от всех находок
- FP исключены из: скора, отчётов, API, ТЗ для разработчика
- Пользователь может пометить FP в UI — исключается навсегда
- Эвристика: `target-blank-noopener`, `empty-link-name`, `target-size`, `console/warning` — частые FP
- Never-FP: `image-alt`, `color-contrast`, `duplicate-id`, ARIA violations

## 7. Вы храните пароли клиентов?

- **SSRF защита:** только http/https, private IP заблокированы
- **Креды — только хосту сайта:** Authorization и Cookie уходят только на домен проверяемого сайта (credscope)
- **robots.txt уважается** по умолчанию (галочка «игнорировать» для своих сайтов)
- **Пароли локально:** зашифрованы Fernet (WEBSCOPE_AUTH_KEY), только для входа при проверке
- **Веб-вход:** опциональный пароль (WEBSCOPE_AUTH_PASSWORD), без ролей

> **Скрытый слайд** — открывать по вопросу о безопасности.

| Вопрос | Ответ |

| «Почему не бесплатно?» | Free = 5 находок. Бесплатный сыр — в мышеловке (нет алертов, нет диффа, нет ТЗ). |

| «Почему не open source?» | Движок — IP. Watchdog и биллинг — SaaS. CLI free для devs. |
| «Где данные хранятся?» | Беларусь, свой VPS. GDPR-ready. Экспорт/удаление за 1 клик. |

## Чего не говорить

- «Миллиарды», «TAM $274 млн» без пометки «оценка сверху».
- «Маржа >90%», «LTV/CAC 7×» — в модели 85% и ~7× (взвешенное).
- «Прогноз 142 клиента» — это сценарий.
- «Проверяем всё» — 2FA, капчи и сложный JS не покрыты.
- «Watchdog готов» — вебхуки в разработке, бета к пятнице.
- «Pay-per-scan запущен» — биллинг в разработке, MVP к понедельнику.
