  Плюс **4 скрытых слайда** для ответов на вопросы (в PDF не печатаются).

Тёмная тема — только титул, финальный слайд и акцентные карточки:
`#0B1026`, текст `#FFFFFF`, вторичный `#9AA2B4`.

7,9:1. Ни одна подпись не светлее 4,5:1.

## Модель и цифры

Одна модель — `ECONOMICS.md`, без «Solo $12» и старых ARPU:

| План | Находок/мес | Сайтов | Цена |
|---|---|---|---|
| Free | 5 (lifetime) | 1 | $0 |
| Starter | 200 | 5 | $19/мес |
| Pro | 1000 | 25 | $59/мес |
| Business | 5000 | 100 | $199/мес |

Находка = уникальное правило × страница.

Обоснование ключевых чисел:

- **5 находок** — 30–40% отчёта: средний сайт даёт 12–18 находок за скан
  (оценка по демо-стенду).
- **Маржа ~85%** — эквайринг ~3% + инфраструктура/LLM < $0,15 на сайт/мес +
  резерв на поддержку.
- **$150/мес** — VPS $90 + LLM $30 + почта $10 + бухгалтерия $20.
- **≈10 клиентов** — `150 / (19 × 0,85) = 9,3`; без зарплат. С временем
  основателя $500/мес — `650 / (19 × 0,85) ≈ 40` клиентов.
- **CAC ~$30** — `$250 теста трафика / 8 платящих` — гипотеза пилота.
- **LTV ~$150** — `8 мес × $19 = $152`; LTV/CAC ≈ 5×; окупаемость ~2 мес.
- **80 аккаунтов → MRR $1 520** — `80 × $19`; выручка 2027 ≈ $9 тыс. с рампой
  (в среднем ~40 платящих). Это сценарий, не прогноз.
- **Бюджет запуска $800** — инфраструктура $120, LLM/почта $60, юридика $200,
  тест трафика $250, резерв $170.
- **Рынок** — 1,2 млн сайтов на WordPress/Tilda в РФ (Inclient, 2026),
  250 тыс. с заявками; 80 аккаунтов = 0,03%.
- **TAM/SAM/SOM** — `$274 млн` / `$57 млн` / `$18 тыс. ARR` — оценки сверху
  при чеке $19, не прогноз.

## Q&A: как пользоваться

`webscope-pitch-qa.md` — 10 вопросов по ~30 секунд. В деке под них есть 4
скрытых слайда: открывать только под тему, иначе не уложиться в 5 минут.

Если факта нет — говорить «не знаю, проверяем на пилоте», а не придумывать
цифру. Все денежные значения — гипотезы, кроме арифметики.

Что не говорить: «миллиарды», «маржа >90%», «LTV/CAC 7×», «прогноз 80
клиентов», «проверяем всё» (2FA, капчи и сложный JS не покрыты).

## Сборка

Нужен `deckcraft-cli` 0.12.0. AppImage распаковывается, потому что CLI лежит
внутри:

```bash
cd /tmp
~/Applications/deckcraft-0.12.0-linux-x86_64.AppImage --appimage-extract
export DECKCRAFT_CLI=/tmp/squashfs-root/usr/bin/deckcraft-cli
```

`build_deck.py` ищет CLI в порядке: `$DECKCRAFT_CLI` → распакованный AppImage →
`PATH`.

```bash
cd /data/Work/qa-startup

# короткая версия: .deckcraft + .pptx + .pdf
python3 pitch/build_short.py

# полная версия
python3 pitch/build_deck.py

# заметки A4 (9 страниц)
"$DECKCRAFT_CLI" run --in pitch/webscope-pitch-3min.deckcraft \
  --cmd 'file.export={"path":"pitch/webscope-pitch-3min-notes.pdf","format":"pdf","layout":"notes","perPage":1,"paper":"a4"}'

# текст слайдов
"$DECKCRAFT_CLI" convert pitch/webscope-pitch-3min.deckcraft \
  pitch/webscope-pitch-3min-outline.md

# PNG для проверки вёрстки
"$DECKCRAFT_CLI" render pitch/webscope-pitch-3min.deckcraft --all --scale 1.5 /tmp/deck
```

Проверка после сборки: в выводе не должно быть строк `✗` и предупреждений
`текст выше блока`. PDF короткой версии — 9 страниц, notes — 9 страниц,
полная — 17.

## Честные границы

- Платящих клиентов — 0, продаж не было. 80 аккаунтов — сценарий.
- FP < 10% — цель, на живом корпусе ещё не измерена.
- 2FA и капчи не поддерживаются, сложный JS — частично.
- Веб-вход — опциональный пароль, без ролей.
- Биллинг в коде — скелет со старыми `PlanName`; тарифы из `ECONOMICS.md`
  ещё не перенесены. Перед публичным SaaS нужны биллинг, лимиты и изоляция
  браузера.
