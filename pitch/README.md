## Дизайн

Визуальная система — редакционная, а не «презентация стартапа»:

- белый лист, чёрный текст, один сигнальный красный `#C9280B`;
- заголовки — Noto Serif Bold, тело — Noto Sans, метки и цифры — Noto Sans Mono;
- никаких карточек, скруглений, теней, иконок и пастельных заливок;
- вместо карточек — линейки, номера, таблицы и воздух;
- тёмные слайды только для ритма: титул, «почему сейчас», финал.

Контраст проверен: тело `#3C434D` — 10:1 на белом, метки `#5A626D` — 6,2:1,
красный — 5,5:1, текст на тёмном — 8,3–13,3:1. Ни одна подпись не светлее
4,5:1. Числа набраны моноширинным шрифтом, поэтому колонки не «пляшут».

Проверка по Web Interface Guidelines (в адаптации к слайдам): контраст,
иерархия, отсутствие декоративных иконок, кавычки-ёлочки, табличные цифры,
активный залог в подписях.

бизнес и ИП; веб-студии вынесены в «позже».

## Позиционирование

Фокус — малый бизнес и ИП: владельцы сайтов, у которых нет техкоманды.

Веб-студии и фрилансеры (в старых версиях — «агентства») — не приоритет.
Это не QA-подрядчики, а студии с клиентскими сайтами: один разговор
может дать портфель, но продажа через них требует времени. Возвращаемся
к ним после стабильного MVP.

План до декабря — технический: точность детектора, отчёты, стабильность,
MCP/CLI, тесты, демо. Интервью, пилоты и продажи в него не входят.

## Цифры и допущения

Цены — в USD, потому что продукт продаётся удалённо; оплата в BYN по курсу.
В короткой версии это сказано на слайде 5; в полной — на слайдах 8 и 12.

- Тарифы: Free `$0`, Solo `$12/мес`, Studio `$59/мес`, Agency `$149/мес`.
  В фокусе — Solo для малого бизнеса и ИП; Studio/Agency — тарифы на будущее,
  не канал продаж.
- ARPU `$18/мес`; COGS — меньше `$0,15` на сайт в месяц; валовая маржа `≈ 85%`
  после платежей и LLM.
- Отток `12%/мес`, CAC `≈ $30` — консервативные гипотезы. LTV/CAC `≈ 4×`
  при такой марже и оттоке.
- Постоянные расходы `≈ $150/мес` (инфраструктура, LLM, почта, бухгалтерия).
  Безубыточность — `10 клиентов` при ARPU `$18` и марже `85%`, **без зарплат**.
  Если оценить время основателя в `$500/мес`, безубыточность — `≈ 43 клиента`.
- Бюджет запуска — `$800`: инфраструктура `$120`, LLM/почта `$60`,
  юридика `$200`, тест трафика `$250`, резерв `$170`. Плюс 4 недели full-time.
  На финальном слайде — те же `$800` на инфраструктуру и тесты.
- Сценарий: `80` платящих сайтов к декабрю 2027, MRR `$1 440`, выручка 2027
  `≈ $9 тыс.`; консервативный — `40` сайтов, MRR `$720`.
  Затраты 2027 — `≈ $4 тыс.` без зарплат. Это сценарий, не прогноз.
- Рынок: `1,2 млн` установок WordPress и Tilda в РФ (Inclient, 2026);
  `250 тыс.` сайтов с заявками; `80` платящих — сценарий.
  TAM `$170 млн/год`, SAM `$36 млн/год`, SOM `$17 тыс. ARR` — оценки сверху,
  не прогноз.
- Статус продукта: 66 тестов, 6 проверок + детектор блокировки кликов,
  CLI / MCP / веб, история и диффы. В полной версии слайд 11 — только
  продуктовый статус; бизнес-метрики туда не вынесены.

Экономика намеренно тихая: на слайде 12 нет ни «миллиардов», ни «маржа >90%»,
ни «LTV/CAC 7×». TAM/SAM в деньгах продублированы в приложении Б и подписаны как оценка.
Все прогнозы помечены как сценарий или гипотеза.

## Пересборка

Нужен распакованный DeckCraft CLI: `/tmp/squashfs-root/usr/bin/deckcraft-cli`.
Если `/tmp` очистился:

```bash
cd /tmp
~/Applications/deckcraft-0.8.0-linux-x86_64.AppImage --appimage-extract
```

Короткая версия:

```bash
cd /data/Work/qa-startup
python3 pitch/build_short.py
```

Скрипт собирает `webscope-pitch-3min.deckcraft`, `.pptx` и `.pdf`.
Заметки и outline — отдельно:

```bash
/tmp/squashfs-root/usr/bin/deckcraft-cli run \
  --in pitch/webscope-pitch-3min.deckcraft \
  --cmd 'file.export={"path":"pitch/webscope-pitch-3min-notes.pdf","format":"pdf","layout":"notes","perPage":1,"paper":"a4"}'

/tmp/squashfs-root/usr/bin/deckcraft-cli convert \
  pitch/webscope-pitch-3min.deckcraft pitch/webscope-pitch-3min-outline.md
```

Полная версия:

```bash
cd /data/Work/qa-startup
python3 pitch/build_deck.py
```

Заметки и outline полной версии:

```bash
/tmp/squashfs-root/usr/bin/deckcraft-cli run \
  --in pitch/webscope-pitch.deckcraft \
  --cmd 'file.export={"path":"pitch/webscope-notes.pdf","format":"pdf","layout":"notes","perPage":1,"paper":"a4"}'

/tmp/squashfs-root/usr/bin/deckcraft-cli convert \
  pitch/webscope-pitch.deckcraft pitch/webscope-pitch-outline.md
```

## Как показывать

1. Для защиты на 3 минуты открыть `webscope-pitch-3min.pdf` — 8 страниц,
   шрифты внутри, вёрстка не поедет.
2. `.pptx` — если нужно править. На чужой машине без Noto Serif / Noto Sans Mono
   PowerPoint подставит системные шрифты; PDF надёжнее.
3. Заметки — на втором экране или в `webscope-pitch-3min-notes.pdf`.
4. Если спросят про проверки, рынок, экономику или бюджет — открыть
   `webscope-pitch.pdf` (полная версия) и приложения A/Б/В. Целиком её
   не показывать.
5. Финал короткой версии — слайд 8: технический план и запрос, не продажа.
   В полной версии то же самое — слайд 14.
