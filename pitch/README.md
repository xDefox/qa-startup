# Питч webscope

Три версии и отдельный Q&A:

- **5 минут, 11 слайдов** — `webscope-pitch-5min.pdf` — актуальная версия для
  питча. Структура по документу Space University. Плюс **5 скрытых слайдов**
  для ответов на вопросы (в PDF не печатаются).
- **3 минуты, 9 слайдов** — `webscope-pitch-3min.pdf` — прошлая короткая версия.
  Плюс **4 скрытых слайда** для ответов на вопросы (в PDF не печатаются).
- **17 слайдов** — `webscope-pitch.pdf` — полная версия, запас на вопросы;
  целиком не показывать.
- **`webscope-pitch-qa.md`** — 10 вопросов на 5 минут, короткие ответы,
  обоснование цифр и список неудобных вопросов.
- **`webscope-survey-2026-11.md`** — аналитика опроса 09–12.11.2026 (67 ответов):
  цифры для слайдов подтверждения и честные границы выборки.

Фокус — технический статус продукта и малый бизнес/ИП. 960×540, DeckCraft.

## Модель и цифры

Две модели оплаты: подписка — основа, пакеты проверок — вход
(`ECONOMICS.md` §2; реализация — `billing.py`, `routes/api.py`, `PLAN.md`).
Пакеты не отменяют подписку.

Подписка:

| План | Находок/мес | Сайтов | Цена |
|---|---|---|---|
| Free | 5 (lifetime) | 1 | $0 |
| Starter | 200 | 5 | $19/мес |
| Pro | 1000 | 25 | $59/мес |
| Business | 5000 | 100 | $199/мес |

Пакеты проверок (pay-per-scan, без подписки):

| Пакет | Проверок | Цена | За проверку |
|---|---|---|---|
| Starter | 10 | $29 | $2,90 |
| Pro | 50 | $99 | $1,98 |
| Agency | 100 | $179 | $1,79 |

Находка = уникальное правило × страница. В пакете считается число проверок,
в подписке — число находок.

Качество: **307 тестов, покрытие 80% строк** (`pytest --cov=webscope`; 1 skipped).

Обоснование ключевых чисел:

- **5 находок** — 30–40% отчёта: средний сайт даёт 12–18 находок за скан
  (оценка по демо-стенду).
- **Маржа ~85%** — эквайринг ~3% + инфраструктура/LLM < $0,15 на сайт/мес +
  резерв на поддержку.
- **$150/мес** — VPS $90 + LLM $30 + почта $10 + бухгалтерия $20.
- **≈10 подписок** — `150 / (19 × 0,85) = 9,3`; без зарплат. С временем
  основателя $500/мес — `650 / (19 × 0,85) ≈ 40` клиентов.
- **≈6 пакетов/мес** — `150 / (29 × 0,85) = 6,1`; пакеты не recurring, нужен
  постоянный приток. Поэтому подписка — основа, пакет — вход.
- **CAC ~$30** — `$250 теста трафика / 8 платящих` — гипотеза пилота.
- **LTV ~$150** — `8 мес × $19 = $152`; LTV/CAC ≈ 5×; окупаемость ~2 мес.
- **80 подписок → MRR $1 520** — `80 × $19`; выручка 2027 ≈ $9 тыс. с рампой
  (в среднем ~40 платящих). Пакеты в сценарий не заложены. Это сценарий, не прогноз.
- **Бюджет запуска $800** — инфраструктура $120, LLM/почта $60, юридика $200,
  тест трафика $250, резерв $170.
- **Рынок** — 1,2 млн сайтов на WordPress/Tilda в РФ (Inclient, 2026),
  250 тыс. с заявками; 80 аккаунтов = 0,03%. Это оценка сверху по РФ;
  старт — в Беларуси, оплата в BYN.
- **TAM/SAM/SOM** — `$274 млн` / `$57 млн` / `$18 тыс. ARR` — оценки сверху
  при чеке $19, не прогноз.

## Q&A: как пользоваться

`webscope-pitch-qa.md` — 10 вопросов по ~30 секунд. В деке под них есть 5
скрытых слайдов: открывать только под тему, иначе не уложиться в 5 минут.

Если факта нет — говорить «не знаю, проверяем на пилоте», а не придумывать
цифру. Все денежные значения — гипотезы, кроме арифметики.

Что не говорить: «миллиарды», «маржа >90%», «LTV/CAC 7×», «прогноз 80
клиентов», «проверяем всё» (2FA, капчи и сложный JS не покрыты).

## Сборка

Нужен `deckcraft-cli` 0.12.0. AppImage распаковывается, потому что CLI лежит
внутри:

```bash
cd /tmp
~/Applications/deckcraft-0.12.0-linux-x86_64.AppImage --appimage-extract
export DECKCRAFT_CLI=/tmp/squashfs-root/usr/bin/deckcraft-cli
```

`build_deck.py` ищет CLI в порядке: `$DECKCRAFT_CLI` → распакованный AppImage →
`PATH`.

```bash
cd /data/Work/qa-startup

# версия на 5 минут: .deckcraft + .pptx + .pdf
python3 pitch/build_pitch5.py

# короткая версия: .deckcraft + .pptx + .pdf
python3 pitch/build_short.py

# полная версия
python3 pitch/build_deck.py

# заметки A4 (11 страниц)
"$DECKCRAFT_CLI" run --in pitch/webscope-pitch-5min.deckcraft \
  --cmd 'file.export={"path":"pitch/webscope-pitch-5min-notes.pdf","format":"pdf","layout":"notes","perPage":1,"paper":"a4"}'

# заметки A4 (9 страниц)
"$DECKCRAFT_CLI" run --in pitch/webscope-pitch-3min.deckcraft \
  --cmd 'file.export={"path":"pitch/webscope-pitch-3min-notes.pdf","format":"pdf","layout":"notes","perPage":1,"paper":"a4"}'

# текст слайдов
"$DECKCRAFT_CLI" convert pitch/webscope-pitch-3min.deckcraft \
  pitch/webscope-pitch-3min-outline.md

# PNG для проверки вёрстки
"$DECKCRAFT_CLI" render pitch/webscope-pitch-3min.deckcraft --all --scale 1.5 /tmp/deck
```

Проверка после сборки: в выводе не должно быть строк `✗` и предупреждений
`текст выше блока`. PDF версии на 5 минут — 11 страниц, notes — 11 страниц;
короткой версии — 9 страниц; полной — 17.

## Честные границы

- Платящих клиентов — 0, продаж не было. 80 аккаунтов — сценарий.
- FP < 10% — цель, на живом корпусе ещё не измерена.
- 2FA и капчи не поддерживаются, сложный JS — частично.
- Веб-вход — опциональный пароль, без ролей.
- Биллинг — скелет: планы Free/Starter/Pro/Business и лимиты находок описаны,
  но Stripe, учёт находок и лимиты ещё не подключены. Перед публичным SaaS
  нужны биллинг, лимиты и изоляция браузера.
