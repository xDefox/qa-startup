## Деплой для питча (запрос Kuga)
- Запрос: задеплоить к следующему питчу, упоминал Vercel («вроде бесплатно даёт запушить»), «сделай напрямую подключение, можно 3».
- **Вердикт: Vercel НЕ подходит** — проект = FastAPI + Playwright/Chromium + SQLite:
  - serverless таймаут 10с (60 на Pro), скан 30–60с;
  - эфемерная ФС (Chromium не поставить, SQLite не переживёт рестарт);
  - нет долгоживущих процессов (сканер, шедулер, вебхуки).
- Проверил: OpenClaw `portal` даёт только `loopback-only` публичный URL — наружу не выводит без VPS/ngrok/Tailscale. Пользователь подтвердил, что «в одной сети» нет.
- **Решение — вариант 1 (Railway/Render)**, подготовлены конфиги:
  - `railway.toml` — builder DOCKERFILE, healthcheckPath `/healthz`, restartPolicy ON_FAILURE.
  - `render.yaml` — Docker web service, healthCheckPath `/healthz`, env WEBSCOPE_HOST/PORT.
  - `Dockerfile` CMD → `sh -c "python -m uvicorn webscope.webapp.app:create_app --factory --host 0.0.0.0 --port ${PORT:-8000}"` (уважает `$PORT` Railway/Render, fallback 8000 для docker-compose/VPS).
  - `.env.example` — шаблон секретов (SECRET_KEY, STRIPE_*, YOOKASSA_*, SMTP_* — можно пустыми для демо).
  - Коммит: `4 files changed, 22 insertions(+), 2 deletions(-)`.
- **Инструкция пользователю**: push → railway.app «Deploy from GitHub repo» → добавить env из `.env.example` → готовый URL. Альтернатива render.com через `render.yaml`.
- Открытых вопросов не осталось; деплой выполняет пользователь (нужен его аккаунт).
